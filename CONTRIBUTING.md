# Contributing to FieldRigger

This template exists so security integrators can help each other improve temporary on-site programming workflows.

## How to Contribute

1. Fork the repository.
2. Make your changes (better prompts, clearer isolation rules, additional brand notes, examples from real jobs, etc.).
3. Open a pull request with a clear description of what you improved and why.
4. Or open an Issue if you want to discuss an idea first.

## What Makes a Good Contribution

- Tightens the isolation or approval model without adding complexity.
- Improves agent prompts so they stay narrow and reliable.
- Adds practical brand or VMS notes that others can reuse.
- Shares real-world failure modes and how the Supervisor should handle them.
- Keeps the template generic so it remains useful across companies.

## Guidelines

- Keep agent roles narrow. One job per agent.
- Preserve the Plan → Approve → Execute → Verify pattern.
- Do not include real credentials, client data, or company-specific secrets.
- Prefer clear, copy-paste-ready prompts.

Thank you for helping make FieldRigger better for the next technician who uses it.
